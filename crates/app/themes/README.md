# Built-in themes

These theme files come unchanged from [gpui-kit](https://github.com/longbridge/gpui-kit/tree/main/themes)
(v0.8.0), Copyright 2024 - 2026 Longbridge, licensed under the Apache License 2.0.
Many are ports of well-known editor themes (Catppuccin, Solarized, Gruvbox, Tokyo Night, …).

They are compiled into OxyPad. Users can add their own in the same format to
OxyPad's themes folder (Settings › Appearance › Open Folder); a file there that
defines a theme with the same name replaces the built-in one.
